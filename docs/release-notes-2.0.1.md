Orgtree 2.0.1 reorganizes secondary account management in Settings.

- Claude, Codex and Antigravity each have an Add secondary account button in their provider header.
- The dialog offers creating a managed profile or importing an existing profile folder. The new account appears under its provider.
- Account rows contain identity, sign-in, refresh and removal controls. Usage remains exclusively in the dedicated Usage modal.
- Import failures stay in the dialog so the folder can be corrected and retried. Accounts with assigned agents still require reassignment before removal.

Existing limitation: secondary Antigravity sign-in is not supported; its rows provide refresh and removal, and the dialog states this limitation. The installer remains unsigned.
