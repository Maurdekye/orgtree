Orgtree 2.0.2 improves provider settings and navigation.

- Provider settings show their previous discovery result immediately while refreshing. Simultaneous discovery requests share a result, and independent provider checks run concurrently.
- Antigravity Sign in again now reaches its existing sign-in handler instead of showing Unknown login provider.
- Secondary Codex accounts show their own sign-in email. The Claude provider divider uses the Claude color.
- Agent card shortcut buttons are optional app-wide and disabled by default under Settings > Display > Desk.
- Inbox and sent-message lists use plain sender names for readability.
- Clicking anywhere inside a pinned modal, or pinning it, raises it to the front.
- Org settings are titled <org name> - org settings.

The first provider discovery can still wait on a slow provider CLI. Secondary Antigravity profile sign-in remains unsupported. The installer remains unsigned.
