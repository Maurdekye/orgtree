## Orgtree 2.0.6

This patch release fixes pinned-window interaction and improves the Usage and Work modals.

- Brings a pinned agent desk in front when you click anywhere in its content, including when the Usage modal overlaps it.
- Aligns every Usage card with the same responsive header layout and keeps the refresh control with its status at narrow widths.
- Shows how long ago usage was updated, while preserving the exact time on hover.
- Opens work-item links from events through the normal formatted ticket detail view, including when the pinned Work modal starts with no selection.
