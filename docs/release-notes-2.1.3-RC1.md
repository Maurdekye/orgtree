# Orgtree 2.1.3-RC1

This is the first release candidate for Orgtree 2.1.3. The installer is
unsigned, as earlier Orgtree releases have been.

The `-RC1` suffix identifies this candidate in the application version,
installer filename, update metadata, and release handoff. Later candidates
will increment the `RC` number; the final 2.1.3 release will omit the suffix.
