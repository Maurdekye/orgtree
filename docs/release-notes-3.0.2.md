# Orgtree 3.0.2

- **Swap the Attention view's panels.** Right-click the divider between the
  two panels and choose **Swap panels** to put the list on the other side.
  Orgtree remembers the choice for each organization.
- **Gemini 4 Argon, when it arrives.** A new Antigravity model, Argon, shown
  in magenta. It appears in the hire and model-switch menus only once the
  Antigravity CLI (`agy models`) lists `gemini-4-argon` for your account; no
  Orgtree update is needed at that point. Until then nothing changes.

This update contains only these two changes on top of 3.0.1.
