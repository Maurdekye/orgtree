# Orgtree 3.0.9-beta.2 (local test build)

- **The window can be dragged by its top bar again** when a pinned panel's
  content is scrolled up under the top bar.
- **Circle view arc reads left to right.** The ring is drawn
  counter-clockwise so a partly filled arc reads like the row, and the hire
  button goes on an open end of the arc.
- **Far-zoom hire tokens let go of the name.** Pressing a hire token no
  longer leaves the agent name showing after the pointer moves away.

Local test build of 3.0.8 plus these fixes (403b53d, fb7a9a4, 1c4354f). Not published.
