# Orgtree 4.4.6

Orgtree 4.4.6 adds OpenAI's GPT-6.1 Terra as a current Codex model.

## Models

- **GPT-6.1 Terra joins the Codex models.** Terra is offered beside Astra, Sol and Luna in every hire and model menu and in the model tier lists, without turning on **Show legacy models**. New Terra agents run GPT-6.1 Terra; agent settings also offer Terra 5.6 as an older version. GPT-6.1 Terra needs Codex CLI 0.159.0 or later and an OpenAI account that offers the model.
- **A Terra seat costs 1 credit instead of 2**, following GPT-6.1 Terra's lower price. Terra agents that are not pinned to a version move to GPT-6.1 Terra on their next turn; agents pinned to Terra 5.6 keep it.
- **Show legacy models now covers Gemini Pro only.** Its name and description in **App settings > Runtime** say so.
