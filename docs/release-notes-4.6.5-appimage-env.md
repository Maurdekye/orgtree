**Linux AppImage without FUSE: use the environment variable.** On a Steam Frame, SteamOS or any Linux without FUSE (`libfuse2`), start the AppImage with `APPIMAGE_EXTRACT_AND_RUN=1` in its environment, not with the `--appimage-extract-and-run` argument the 4.6.4 notes named. The AppImage's launcher removes the argument, so the restart after an update would try FUSE and fail to start; the variable carries over. In Steam, set the launch options to `APPIMAGE_EXTRACT_AND_RUN=1 %command%`. Keep the file at one fixed path in a folder you can write to: updates replace it in place, and the background engine's login registration names that path. See [Getting started](getting-started.md#linux-appimage-without-fuse).
