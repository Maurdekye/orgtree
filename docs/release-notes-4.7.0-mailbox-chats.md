## Your Inbox, as chats

- **The Inbox is now a list of chats**, like Hubchat. Every top-level agent and every agent you gave an audience has a chat, newest first, each with its unread count. Your mail, requests and audiences are the same as before; only the view changed. The Inbox button is now a chat bubble.
- **Closing a chat takes back that agent's audience**, at once and without a confirmation. Its mail is kept. A top-level agent's chat can't be closed, and the close button's tooltip says why.
- **New chat** opens the agents list. Picking an agent opens its chat and gives it an audience if it had none.
- **Questions and requests appear in the chat** of the agent that asked, one bubble per question with one submit. Notices have a dashed border, requests a small label, and files are chips.
- **Agents answer you by mail.** A new message you type in a chat tells the agent to reply by mail, so its answer shows up in the chat.
- **Replying to a presentation or a ticket opens that agent's chat**, with your reply as the latest message. You can turn this off in App settings > Display > Mailbox.
- **Prefer the mailbox as it was?** Tick **classic** in the Inbox's title bar, or turn on App settings > Display > Mailbox > Classic mailbox. It brings back the previous panel and its mail icon on this computer. See [your Inbox as chats](messages-and-work.md#your-inbox-as-chats).
