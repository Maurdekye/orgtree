actor. The actor coalesces output frames to at most4Hz. Turn-start/tool identity
and revision prevent stale previews replacing newer ones. Native ACP execution
kind can identify a shell whose title is the command itself without changing
that tool's collapsed display. Extra concurrent tools have no retained preview
until capacity is available; their final results still use the existing path.

the shared conversation store supplies expanded ToolChip rows. Closed rows
render no preview bytes. A final result replaces the live display. End, exit,
interrupt and turn replacement discard transient bytes. No preview is placed in

previews and private failed-shell1MiB retention are unchanged.

All byte-bearing Rust handlers/helpers are `#[nolog]`; diagnostics must remain
metadata only. Output is escaped React preformatted text, not raw HTML. This
does not claim arbitrary secret detection. Existing transcript authorization
still governs recipients. Output traffic adds bounded memory/CPU and viewer
bandwidth, not model tokens or inference charges.
