# orgtree-desk

An agent's desk and the work panels: chat, history, files, inboxes, ask cards, dockets, presentations and watchdogs.

## Screens

- [orgtree-agent-desk](agent-desk/SKILL.md): The desk: opening it, header actions, banners (turn status, halted, queued, cache forecast) and the tab strip.
- [orgtree-desk-chat](desk-chat/SKILL.md): The Chat tab: transcript, tool chips, thoughts, event cards and the composer.
- [orgtree-desk-history](desk-history/SKILL.md): The History tab shows retained agent event records.
- [orgtree-desk-files](desk-files/SKILL.md): The Files tab: live scratch-folder browser.
- [orgtree-inbox-screens](inbox-screens/SKILL.md): The user inbox, an agent's inbox (modal and desk tab), the org inbox, and the transfers panel.
- [orgtree-ask-cards](ask-cards/SKILL.md): Ask cards: answering questions, credit requests and batch asks.
- [orgtree-docket-screens](docket-screens/SKILL.md): The Work modal, agent and team dockets, the desk Docket tab and the item pane.
- [orgtree-presentations](presentations/SKILL.md): Presented documents: galleries, the document reader and file cards.
- [orgtree-watchdog-panel](watchdog-panel/SKILL.md): The watchdog panel and dog chips.
