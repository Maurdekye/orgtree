# Collaboration patterns

| Workflow | Use it for |
| --- | --- |
| [orgtree-committee-mode](committee-mode/SKILL.md) | A question, design or plan requested by committee: different models propose independently, then revise through the supervisor until consensus or the round limit. |
| [orgtree-dev-team](dev-team/SKILL.md) | Building a deliverable with a coordinator, implementer, redteam reviewer and curator, following the bundled development-team templates. |
| [orgtree-iterative-development](iterative-development/SKILL.md) | Alternating rapid specification feedback and explicit hardening, with release lines, feature freeze and build delivery. |

The committee produces a decision or an explicit undetermined result. The dev-team gives one implementer responsibility for a deliverable; iterative development supplies a release process that team can adopt. The supervisor may use a committee to answer a design question before assigning development, within the user's scope.
