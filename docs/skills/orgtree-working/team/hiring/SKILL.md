# Plan a hire

Start with the work, its current owner and the expertise already available. Read the relevant docket scope and archived-agent history before creating another identity. A retired expert is useful when its decisions and code knowledge still apply; a fresh role is useful when the old conversation would mostly be irrelevant reading. The restore mechanics and session limits live in [rehire](../tool-rehire/SKILL.md).

Match model capability and reasoning effort to the task's difficulty. A routine check rarely needs the same model as a difficult concurrency investigation. This is a staffing judgment, not a rule that a model name proves competence or that every organization must use this team's tier preferences. Look up current identifiers and seat costs with [list tiers](../tool-list-tiers/SKILL.md); account eligibility and usage are separate decisions. See `orgtree-providers-tab` (orgtree-app › providers) for provider controls, and [account lanes](../../accounts/account-lanes/SKILL.md) for account selection.

Choose the smallest effective scope that lets the worker complete the objective, then write the role's standing charter in full. Put the immediate assignment in kickoff or a docket assignment rather than hoping the role description starts work. Hiring is not task fan-out by itself. [Hire](../tool-hire/SKILL.md) owns the exact fields, explicit ordinary-hire requirements, insertion index, inherited superior scope and transaction behavior.

For an existing live worker, assign the docket item. When both the worker and the item need creation/restoration, use [staff](../../docket/tool-staff/SKILL.md). Before committing the placement, inspect the payer's [credits](../credits/SKILL.md) and whether a new management layer is justified. Afterward, read the result and warnings, verify the actual owner and first message, and leave one clear next action for the worker.

For the human's draft-card flow, see `orgtree-draft-hires` (orgtree-app › canvas). Its staged form has user defaults; do not copy that omission behavior into an agent hire call.
